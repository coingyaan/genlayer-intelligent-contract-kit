# Deployment Guide

## Requirements

- GenLayer Studio
- py-genlayer
- Connected Wallet

---

## Deployment Steps

1. Open GenLayer Studio.

2. Create a new contract.

3. Copy the desired contract from the `contracts` folder.

4. Paste it into the editor.

5. Deploy the contract.

6. Provide constructor parameters.

7. Wait for consensus.

8. Save the deployed contract address.
